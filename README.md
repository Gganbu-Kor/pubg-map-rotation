## 2. 왜 했나 (문제 정의)
- PUBG는 업데이트마다 지역별 맵 선호도(플레이타임·매치 수·선택률·이탈률 종합)를 공개하고, 이를 기준으로 고정·선호 맵을 정한다.
- 하지만 이 선호도에는 사람과 봇의 구분이 없다. 첫 테스트에서 본 매치는 참가자의 77~94%가 봇이었다.
- 공식 선호도를 정답지로 내 계산 방법을 검증하고, 봇을 뺀 사람 기준으로 다시 보면 맵 간 격차와 하위 맵의 매칭 품질이 어떻게 보이는지 확인한다.

## 3. 핵심 질문
- Q1. 아시아 서버 최근 14일 매치 비중의 맵 순위는 공식 43.2 선호도 순위와 일치하는가?
- Q2. 봇을 빼고 사람만 세면 맵 간 격차가 얼마나 벌어지는가? 하위 맵은 한 판에 실제 사람이 몇 명인가?
- Q3. (선택) 모드별·주차별로 비중이 어떻게 다른가?
