## 2. 텔레메트리 앞부분으로 지역 판별 (`src/check_region.py`)

방법: steam 매치 ID 9,709개 중 20건을 무작위 추출(seed 42) → 매치 조회 → 텔레메트리를 16KB씩 받다가 `MatchId`를 찾으면 즉시 중단

### 2-1. 실현 가능성

| 항목 | 결과 |
|---|---|
| 지역 코드 추출 성공 | **20 / 20건** |
| 필요한 다운로드 | 첫 16KB 한 조각이면 충분 (평균 15KB) |
| 전체 파일 크기 (압축 상태) | 평균 1.4MB → **약 1%만 받음** |
| 매치 1건당 소요 | 매치 조회 0.91초 + 텔레메트리 1.12초 = **약 2.0초** |
| 전체 9,709건을 1건씩 처리하면 | **약 5.5시간** |

→ 텔레메트리 방식은 **사용 가능**. 매치 조회로 일반 매치만 먼저 거르고 그 매치만 텔레메트리를 받으면 시간을 줄일 수 있다.

## 3. 2,000건 기준 추정

### 3-1. 20건 테스트
- official + as = 7건 (35%) → 9,709 × 35% ≈ 3,400건
- 95% 신뢰구간(Wilson) 약 18%~57% → 약 1,800 ~ 5,500건. 하한이 2,000건 아래라 확정 불가 → 100건으로 재측정

### 3-2. 100건 재측정 (같은 방법, seed 42)

| 항목 | 결과 |
|---|---|
| 지역 코드 추출 성공 | **100 / 100건** (지역을 못 읽은 매치 0건, MatchId 구조 28종 모두 동일) |
| 지역 분포 | as 73, sea 16, eu 3, ru 3, sa 3, na 2 |
| matchType 분포 | official 50, airoyale 22, tutorialatoz 12, competitive 11, trainingroom 5 |
| 커스텀 매치 | 0건 |
| 매치 1건당 소요 | 평균 1.06초 → 9,709건 순서대로 처리 시 약 2.9시간 |
| **official + as** | **36 / 100건 (36%)**, 95% 신뢰구간 27% ~ 46% |

→ 신뢰구간 하한(약 2,650건)도 2,000건을 넘으므로 **"아시아 일반 매치 2,000건 이상" 기준은 달성 가능**

## 4. 눈에 띈 점 (20건만 본 것이라 일반화 금지)

- **samples에는 모든 matchType이 섞여 있음** → 분석 때 `matchType = official`, `isCustomMatch = false`로 거르면 캐주얼·경쟁전·훈련장·튜토리얼은 빠짐
- **캐주얼·경쟁전의 인원 구성은 게임 규칙으로 정해져 있음** (사용자 도메인 지식으로 확인)
  - 경쟁전(competitive): 사람만, 최대 64명 → 4건 모두 봇 0명, 사람 60~62명으로 **규칙과 일치**
  - 캐주얼(airoyale): 규칙상 봇 88명 + 사람 12명 → 실제 5건은 **봇 91~92명 + 사람 6~7명**으로 규칙과 다름. 12명은 최대 인원이라 다 채워지지 않았거나 규칙이 바뀌었을 가능성이 있음. 분석 범위 밖이라 결과에는 영향 없음
  - 따라서 두 모드의 봇 비율은 "발견"이 아니라 시스템 설계값이고, 분석 대상인 일반 매치만 봇 비율이 실제로 달라짐
  - 일반 squad는 대부분 사람이 90명 이상이지만 33/95, 58/98인 경우도 있음
  - 일반 solo·duo는 사람 11~14명 / 99~100명
- Day 1에서 본 "봇 77~94%" 2건은 각각 일반 solo-fpp(na), 일반 squad(kakao)였음 → 모든 매치가 그렇다고 볼 수는 없음
